# Changelog

## v1.2.0 - Android64 Edition

- Rebuilt the project as an Android64-only Geode mod for Geometry Dash 2.2091.
- Added a mobile dashboard with Analyzer, Frame Lab, ID Map, Snapshots, Visualizer, Performance, Macro Lab and Project sections.
- Expanded the platform-independent core with level validation, fixture parsing, ID usage counters, frame statistics, snapshots, FPS profiling and macro event import/export.
- Added standalone core regression tests and made them part of the Android64 workflow.
- Documented which functions are core-ready and which still need live editor/input hooks.
